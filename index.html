What is DNA?

DNA is like a recipe book inside every living thing! It tells your body how to grow, what color eyes you'll have, and makes you unique!

DNA is made of 4 special letters called bases:

A
Adenine
T
Thymine
G
Guanine
C
Cytosine

DNA Pairs

DNA bases always pair up like best friends:

A T
G C

This is called base pairing! It's like a zipper that holds DNA together.

Why DNA Matters

DNA helps doctors and scientists:

  • Find cures for diseases
  • Grow better food
  • Protect endangered animals
  • Understand families and ancestry
  • Discover new medicines

How Computers Help Scientists Study DNA

Human DNA has 3 BILLION letters! That's like 3,000 books. Computers help scientists read and understand all this information super fast!

DNA Code

ATGCATGC

Made of: A, T, G, C

Found in: All living things

Computer Code

01001010

Made of: 0, 1 (Binary)

Found in: All computers

What is BLAST?

BLAST stands for Basic Local Alignment Search Tool

It's like a super-fast search engine for DNA! Scientists use it to:

  • Find matching DNA patterns
  • Compare genes from different animals
  • Identify bacteria and viruses
  • Develop new medicines
// How a computer reads DNA
let dna = "ATGCATGC";
let pattern = "ATG";
// Search for pattern in DNA
function findPattern(dna, pattern) {
  return dna.indexOf(pattern);
}

Real-World Impact

During COVID-19, scientists used computer programs like BLAST to study the virus DNA and create vaccines in record time! Computers analyzed millions of DNA sequences to understand the virus and save lives.

Cool DNA Computer Facts

  • Scientists worldwide share DNA data through the internet
  • AI helps predict what genes do
  • Your smartphone has enough power to analyze DNA!
