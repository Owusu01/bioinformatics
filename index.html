What is BLAST?

BLAST — Basic Local Alignment Search Tool — is like a super-fast search engine for DNA.

  • Find matching DNA patterns
  • Compare genes from different animals
  • Identify bacteria and viruses
  • Develop new medicines
// How a computer reads DNA — JavaScript let dna = "ATGCATGCGGTA"; let pattern = "ATG"; function blastSearch(dna, pattern) { const positions = []; for (let i = 0; i <= dna.length - pattern.length; i++) { if (dna.slice(i, i + pattern.length) === pattern) positions.push(i); } return positions; } // Result: Found at positions [0, 4]

Real-World Impact

During COVID-19, scientists used tools like BLAST to study the virus genome and design vaccines in record time. Computers analysed millions of sequences to help save lives worldwide.
